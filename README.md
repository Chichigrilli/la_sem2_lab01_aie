# Лабораторная работа: Тензорные разложения и формат Tensor Train

## Описание
В данной лабораторной работе требуется реализовать алгоритм **TT-SVD** для перехода от плотных многомерных массивов к компактному тензорному формату **Tensor Train (TT)**. 
Вы на практике столкнетесь с преодолением «проклятия размерности» и научитесь сжимать данные, сохраняя их структуру.

Реализация должна строго соответствовать заданным сигнатурам классов и функций. Проверка корректности решений (совпадение тензоров, рангов аппроксимации и вычислительной сложности) осуществляется автоматически с помощью **GitHub Actions**.
